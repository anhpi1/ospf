# Task Spec: T-01 — Project Setup

> Thiết lập project OMNeT++, Makefile và cấu trúc thư mục.

---

## 1. Overview
Khởi tạo OMNeT++ project để compile OSPF routing simulation. Dùng `opp_makemake` để tạo Makefile tự động.

## 2. Requirements
- OMNeT++ 6.4.0 installed với `opp_makemake` trong PATH
- Thư mục project rỗng

## 3. Input
- `opp_makemake` tool
- C++ compiler (g++)

## 4. Process
```bash
mkdir -p src simulations results
cd src && opp_makemake -f --deep -o ospf_sim -O ../out -I.
cd .. && make -f src/Makefile
```

## 5. Output
- `Makefile` (symlink hoặc generated)
- `src/Makefile` (generated by opp_makemake)
- `out/` (build output directory)

## 6. Acceptance Criteria
- `make` chạy không lỗi (dù chưa có source code hợp lệ)

## 7. Related Tasks
- T-02 (NED): cần thư mục `simulations/`
- T-03 (.msg): cần thư mục `src/`
- T-04 (Skeleton): cần Makefile compile được

## 8. Notes
- Nếu dùng IDE: import project từ Eclipse/OMNeT++ IDE
- Môi trường: WSL2 với OMNeT++ 6.4.0
