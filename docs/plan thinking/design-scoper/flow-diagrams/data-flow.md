# Data Flow Diagram — Inter-Task Data Flow

> Luồng dữ liệu giữa các tasks: input → process → output → channel.
> Phase 3, B2.

---

## Data Flow Overview

```
T-01 (Setup) ──── filesystem ────→ T-02 (NED) ──── ned_file ───────→ T-15 (.ini)
                                      │                                  │
                                      │           ini_file               │
                                      └─────────── ... ─────────────────┘
T-01 (Setup) ──── filesystem ────→ T-03 (.msg) ──── msg_h/cc ──────→ T-04 (Skeleton)
                                                                         │
                              ┌──────────────────────────────────────────┤
                              │                                          │
                              ▼                                          ▼
                         T-05 (Hello) ──→ neighbor_state ──→ T-06 (Neighbor FSM)
                              │                                          │
                              │                                    neighbor_state
                              │                                          │
                              ▼                                          ▼
                         T-08 (LSDB)   ◄──── LSA_data ────── T-07b (LSR/LSU)
                              │            (from LSU)              │
                              │                              LSA_request
                              │                                    │
                              │                              T-07a (DD Exchange)
                              │                                    │
                              │                              adj_state + lsa_headers
                              │                                    │
                              ▼                                    │
                         T-09 (Flooding) ◄─────────────────────────┘
                              │             (new LSA notification)
                              │
                              ▼
                         T-10a (SPF)
                              │
                              ▼
                         T-10b (Routing Table)
                              │
                    ┌─────────┴─────────┐
                    │                   │
                    ▼                   ▼
               T-12 (Forward)      T-14 (Dump)
                    │
                    ▼
               T-11 (Client) ─── data_packet ──→ T-12
                    │
                    ▼
               T-13 (Logger) ◄── all_events ──── (từ mọi task)
                    │
                    ▼
               transaction.log + content.log
```

## Per-Task Data Flow

### T-01 → T-02 (Setup → NED)

| Field | Detail |
|---|---|
| **Output (T-01)** | Project directories: `src/`, `simulations/`, `results/` |
| **Input (T-02)** | Empty `simulations/` directory |
| **Process** | Viết file .ned với topology 10 router |
| **Output (T-02)** | `simulations/OspfNetwork.ned` |
| **Channel** | **File system** — write .ned file |
| **Format** | NED language text |

### T-01 → T-03 (Setup → .msg)

| Field | Detail |
|---|---|
| **Output (T-01)** | `src/` directory |
| **Input (T-03)** | Empty `src/` directory |
| **Process** | Viết OspfPacket.msg với 5 packet types + LSA |
| **Output (T-03)** | `src/OspfPacket.msg` |
| **Channel** | **File system** — write .msg file |
| **Format** | OMNeT++ .msg language |

### T-03 → T-04 (.msg → Skeleton)

| Field | Detail |
|---|---|
| **Output (T-03)** | `OspfPacket_m.h`, `OspfPacket_m.cc` (generated by opp_msgc) |
| **Input (T-04)** | OspfPacket classes |
| **Process** | Nhúng OspfPacket_m.h, sử dụng các class trong skeleton |
| **Output (T-04)** | `OspfRouter.h`, `OspfRouter.cc` |
| **Channel** | **C++ #include** + opp_msgc compile |

### T-04 → T-05 (Skeleton → Hello)

| Field | Detail |
|---|---|
| **Output (T-04)** | OspfRouter class, `handleMessage()`, `ppg[]` gates |
| **Input (T-05)** | OspfRouter, OspfHello class |
| **Process** | `sendHello()`: create OspfHello → scheduleAt → send; `processHello()`: parse → update |
| **Output (T-05)** | Hello packets + neighbor state (partial) |
| **Channel** | **In-memory** — trực tiếp gọi method, schedule timer trong cùng module |

### T-05 → T-06 (Hello → Neighbor FSM)

| Field | Detail |
|---|---|
| **Output (T-05)** | `neighborState` (down, init, 2way) từ Hello events |
| **Input (T-06)** | HelloReceived events, InactivityTimer |
| **Process** | cFSM transitions: Down→Init→2Way→ExStart→Exchange→Loading→Full |
| **Output (T-06)** | `adjacencyState`, `neighborRouterID`, `deadTimer` |
| **Channel** | **In-memory** — shared state trong OspfRouter |

### T-06 → T-07a (Neighbor FSM → DD Exchange)

| Field | Detail |
|---|---|
| **Output (T-06)** | AdjacencyOK event (2Way → ExStart) |
| **Input (T-07a)** | Neighbor in ExStart state |
| **Process** | Master/slave negotiation → DD packet exchange |
| **Output (T-07a)** | LSA request list (missing LSAs) |
| **Channel** | **In-memory** + **OMNeT++ send()** cho DD packets |

### T-08 ←→ T-07a/T-07b (LSDB ↔ DB Exchange)

| Field | Detail |
|---|---|
| **Output (T-07a → T-07b)** | LSA request list |
| **Input (T-07b)** | LSA request list, LSDB content |
| **Process** | T-07b sends LSR → receives LSU → installs LSAs into LSDB |
| **Output (T-08)** | LSDB with new LSAs |
| **Channel** | **In-memory** — LSDB methods (installLSA, lookupLSA, getAllLSAs) |
| **Format** | `std::map<LSAKey, RouterLSA>` |

### T-08 → T-09 (LSDB → Flooding)

| Field | Detail |
|---|---|
| **Output (T-08)** | New LSA notification (LSA vừa install) |
| **Input (T-09)** | New LSA, list of interfaces |
| **Process** | Create LSU → send to all interfaces except incoming |
| **Output (T-09)** | LSU packets on wire |
| **Channel** | **In-memory** (notification) + **OMNeT++ send()** (LSU packets) |

### T-08 + T-09 → T-10a (LSDB+Flooding → SPF)

| Field | Detail |
|---|---|
| **Output (T-08)** | Complete LSDB |
| **Input (T-10a)** | LSDB (all RouterLSAs), self routerID |
| **Process** | Dijkstra: build graph → calculate shortest paths |
| **Output (T-10a)** | `{destination, cost, [predecessors]}` |
| **Channel** | **In-memory** — SPFCalculator reads LSDB, writes to intermediate struct |

### T-10a → T-10b (SPF → Routing Table)

| Field | Detail |
|---|---|
| **Output (T-10a)** | SPF result |
| **Input (T-10b)** | SPF result, interface list |
| **Process** | Convert SPF result → RoutingEntries, resolve ECMP |
| **Output (T-10b)** | `vector<RoutingEntry>` (dest, cost, [nextHops]) |
| **Channel** | **In-memory** — direct method return |

### T-10b → T-12 (Routing Table → Forwarding)

| Field | Detail |
|---|---|
| **Output (T-10b)** | Stable routing table |
| **Input (T-12)** | Routing table, data packet |
| **Process** | `lookup(destination)` → get next-hop → send |
| **Output (T-12)** | Data packet forwarded |
| **Channel** | **In-memory** — routing table reference + **send()** |

### T-11 → T-12 (Client → Forwarding)

| Field | Detail |
|---|---|
| **Output (T-11)** | DataPacket (src=10.0.0.6, dst=10.0.0.10, payload=~100B) |
| **Input (T-12)** | DataPacket từ local gate |
| **Process** | forwardData() |
| **Output (T-12)** | DataPacket forwarded to next-hop |
| **Channel** | **OMNeT++ send()** — local gate → OspfRouter |

### T-12 → T-11 (Forwarding → Client delivery)

| Field | Detail |
|---|---|
| **Output (T-12)** | DataPacket đến đích (R10) |
| **Input (T-11)** | DataPacket from OspfRouter local gate |
| **Process** | Nhận data packet |
| **Output (T-11)** | Đánh dấu "delivered" |
| **Channel** | **OMNeT++ send()** — OspfRouter → Client local gate |

### All Tasks → T-13 (Logger)

| Field | Detail |
|---|---|
| **Output (All tasks)** | Actions (send/receive/timeout/state change), packet contents |
| **Input (T-13)** | Events from OspfRouter |
| **Process** | `logTx()`: increment txID → format → write; `logContent()`: dump packet fields → write |
| **Output (T-13)** | `results/transaction.log`, `results/content.log` |
| **Channel** | **In-memory** (Logger singleton) + **File system** (file I/O) |
| **Format** | `[TX-001] T=1.5s 10.0.0.1→10.0.0.2 HELLO neighbors=[2]` |

### T-10b → T-14 (Routing Table → Dump)

| Field | Detail |
|---|---|
| **Output (T-10b)** | Routing table (freshly calculated) |
| **Input (T-14)** | Routing table reference |
| **Process** | `dump()`: iterate entries → format → EV output; measure convergence |
| **Output (T-14)** | Console/log output, convergence time metric |
| **Channel** | **In-memory** (routing table ref) + **OMNeT++ EV/log** |

### T-02 → T-15 (NED → .ini)

| Field | Detail |
|---|---|
| **Output (T-02)** | NED module names, gate names |
| **Input (T-15)** | NED module hierarchy, parameter names |
| **Process** | Viết .ini với network config + parameter values |
| **Output (T-15)** | `simulations/omnetpp.ini` |
| **Channel** | **File system** — write .ini file |

### T-15 → T-16 (.ini → Scenarios)

| Field | Detail |
|---|---|
| **Output (T-15)** | Base .ini config |
| **Input (T-16)** | Base .ini config |
| **Process** | Add [Config] sections for each scenario + ScenarioManager triggers |
| **Output (T-16)** | 5 config sections in omnetpp.ini |
| **Channel** | **File system** — edit .ini file |

### All Tasks → T-17 (Integration Test)

| Field | Detail |
|---|---|
| **Output (All)** | Compiled binary, all configs |
| **Input (T-17)** | Binary + .ini + .ned + .msg |
| **Process** | Run `make` → run each scenario → verify outputs |
| **Output (T-17)** | Verified results (routing tables correct, logs correct) |
| **Channel** | **Shell** (make + opp_run) + **File system** (read results) |

## Channel Types Summary

| Channel | Used By | Đặc điểm |
|---|---|---|
| **File system** | T-02, T-03, T-13, T-15, T-16, T-17 | Write/read files: .ned, .msg, .log, .ini |
| **In-memory** | T-04→T-14 (internal) | C++ objects, method calls, shared state |
| **OMNeT++ send()** | T-05, T-07a, T-07b, T-09, T-12 | Packet passing giữa các modules qua gates |
| **OMNeT++ scheduling** | T-05, T-06, T-07b, T-09 | `scheduleAt()` cho timers |
| **Shell/CLI** | T-17 | make, opp_run |
| **EV/log output** | T-14, T-17 | Console output, result logging |
