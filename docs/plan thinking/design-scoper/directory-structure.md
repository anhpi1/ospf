## Note on OspfRouter.cc Size

OspfRouter.cc sẽ chứa nhiều logic:
- Hello (T-05) ~100 lines
- Neighbor FSM (T-06) ~150 lines
- DB Exchange (T-07a/b) ~200 lines
- Flooding (T-09) ~100 lines
- Forwarding (T-12) ~50 lines
- Dump (T-14) ~50 lines

**Tổng ~650 lines** — 1 file vẫn ổn. Nếu >1000 thì có thể split thành:
- `OspfRouter.cc` (main + dispatch)
- `OspfNeighbor.cc` (FSM + Hello)
- `OspfDbExchange.cc` (DD + LSR/LSU)
- `OspfFlooding.cc`
- `OspfForwarder.cc`
